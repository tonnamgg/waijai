# ไว้ใจ (Waijai) — ตัวกลางพักเงินซื้อขายออนไลน์

เว็บแอป mobile-first ตาม [SPEC.md](SPEC.md) — Next.js 15 + TypeScript + Tailwind + Prisma (SQLite) + framer-motion

## วิธีรัน

```bash
npm install          # ครั้งแรก
npm run setup        # สร้างฐานข้อมูล SQLite + ใส่ข้อมูลตัวอย่าง
npm run dev          # เปิด http://localhost:3000
```

คำสั่งอื่น

| คำสั่ง | ทำอะไร |
|---|---|
| `npm test` | unit test state machine + การคำนวณเงิน (Vitest) |
| `npm run db:reset` | ล้างฐานข้อมูลแล้ว seed ใหม่ |
| `npm run build && npm start` | รันแบบ production |

## ลองเดโม flow เต็ม (ผู้ซื้อ ↔ ผู้ขาย)

ระบบล็อกอินจริงยังไม่ทำ (Milestone 9) — ใช้ **หน้า "บัญชี" → สลับผู้ใช้** แทน
ผู้ใช้ตัวอย่าง: `mint` (ค่าเริ่มต้น), `gadgetbkk`, `ploy.p`, `filmhouse`, `admin`

1. เป็น **มินท์** → กด "สร้างรายการซื้อขาย" → เลือก "ฉันเป็นผู้ซื้อ" → ใส่ผู้ขาย `@gadgetbkk` → สร้าง
2. หน้ารายการ → เปิด "โหมดทดสอบ" → **สลับเป็นอีกฝ่าย** → เปิดลิงก์แชร์ (`/o/...`) → "รับรายการ"
3. สลับกลับเป็นมินท์ → **จ่ายเงินเข้าตัวกลาง** (PromptPay จำลอง: รอ QR ~4 วิ หรือกด "จำลองว่าสแกนจ่ายแล้ว")
4. เป็น gadgetbkk → **ส่งของแล้ว · ใส่เลขพัสดุ** (ต้องแนบรูปตอนแพ็ก)
5. เป็นมินท์ → **ได้รับของแล้ว · ตรวจสอบสินค้า** → ติ๊กเช็กลิสต์ → **ของตรงปก · ปล่อยเงิน** → หน้าเสร็จสิ้น + ให้ดาว + ใบเสร็จ

ข้อพิพาท: ในหน้าตรวจของกด "ไม่ตรงปก · ขอคืนเงิน" (ต้องแนบหลักฐาน) → ผู้ขายส่งคำชี้แจงได้ → สลับเป็น `admin` → บัญชี → "จัดการข้อพิพาท"

Deadline: ปุ่ม "โหมดทดสอบ → ข้ามเวลา" ในหน้ารายการ จะเลื่อน deadline ให้หมดแล้วรัน cron ทันที (auto-cancel / auto-refund / auto-release / แจ้งของไม่มา 14 วัน)
cron ภายในรันทุก 60 วินาทีอยู่แล้ว (`src/instrumentation-node.ts`) และเรียกจากภายนอกได้ที่ `GET /api/cron/tick?secret=$CRON_SECRET`

## หมายเหตุการออกแบบ

- ค่าบริการ 2% **ปัดลงเป็นบาทเต็ม** ขั้นต่ำ ฿10 (ให้ ฿1,290 → ฿25 ตรงดีไซน์) — แก้ได้ที่ `src/lib/config.ts`
- คืนเงินกรณีผู้ขายไม่ส่ง/แอดมินตัดสินคืน = คืน **เต็มจำนวนรวมค่าบริการ**
- ผู้ซื้อจ่ายได้เมื่อผู้ขายกดรับรายการแล้วเท่านั้น; ถ้าระบุ `@username` ที่มีอยู่จริง เฉพาะคนนั้นที่รับลิงก์ได้
- SQLite ไม่มี enum/String[] → เก็บเป็น String/JSON และตรวจชนิดใน TypeScript (`src/lib/types.ts`)
- "ดาวน์โหลดใบเสร็จ" เปิดหน้าใบเสร็จแล้วสั่งพิมพ์ → บันทึกเป็น PDF จากเบราว์เซอร์
- อ่าน SPEC ข้อ 12 (กฎหมาย/KYC/PDPA) ก่อนใช้งานจริง
